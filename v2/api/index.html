来源与计算口径
  • UN Comtrade 中国报告方代码 156。年度税则明细优先采用 HS8，HS6 采用对应商品组。出口金额按原表美元。直接海关核验状态随数据保留。
  • 净重优先取 netWgt，有效公斤数量覆盖金额低于 99.5% 时不计算汇总单位金额。默认严格口径隐去估算或估算状态缺失的单位金额。重点品种可用参考视图复算带标签的观察值。
  • 贸易伙伴按 UN Comtrade 原始统计代码显示。法国 250 是法国本土，251 为法国和摩纳哥范围。美国 840 为美国，842 为美国及波多黎各、美属维尔京群岛范围。瑞士 756 为瑞士，757 为瑞士及列支敦士登范围。代码可在同一年并存，目的地明细保留各代码。按伙伴加总的全球值沿用原表统计切片，地理重复范围仍待与海关直接总计核对。
  • 历史区间内税则范围变化单独标出。宽税号的金额与单位金额反映申报组合。维生素 D3 和 B12、硫氰酸红霉素、肝素粗品和低分子肝素优先通过可核对的分子披露及注册材料追踪。
