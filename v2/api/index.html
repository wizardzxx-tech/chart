来源与计算口径
  • 来源为 UN Comtrade 收录的中国报告方数据（156），采用年度贸易统计和中国税则号列统计。出口金额通常为 FOB，进口金额通常为 CIF，均为当年美元。
  • 8 位原表无全球合计时，按不同国家或地区的明细汇总。金额有记录而有效数量覆盖金额不足 99.5% 时，汇总数量及单位金额留空。主表的数量采用净重或适配的法定计数单位。
  • 单位金额＝贸易金额 ÷ 同一行有效数量。产品结构、型号、目的地和计量会影响这一指标。器械出口量与进口量不能直接用于计算国产替代率。
  • 疫苗按净重计量，包含的品种与剂型随贸易构成变化，净重不能换算剂数。
  • 进口伙伴、出口目的地沿用统计申报口径，可能涉及转口。历史编码发生调整时在趋势图中标出实际编码，历史税目范围以各年税则为准。
