# 第二阶段研究数据更新

## 实际更新路径

- 国家医保局的基金统筹收支走公告发现、官方图片、按网格识别、累计与分项校验、人工批准。批准结果写入医保原 CSV、趋势 JSON 和页面的累计图。官方原图链接及 SHA-256 与核准收执一起保存；本机可重放缓存内的原图。
- 中检院公告按产品与持证主体归一化，从证书号去重。分别展示中检院统计和全国历史。地方机构发布区间可能跨周、晚发或缺表，部分机构的索引有重叠记录时也不能将中检院批数替代全国值。
- 标准财务先采用有明确定义的 A 股合并报表字段与 SEC USD XBRL 财务口径。公司注册表用于 A/H/美股公告轮询。港股港币财报与境外公司非标准财年需要逐公司处理，既有半年／年度 CCC 保留。对受限公司与公告返回错误按证券留痕。门店、浆站、手术量及财报重分类保留审核。
- Comtrade 实际量价先覆盖 CT、MRI、6-APA、维生素 E 编码和人用疫苗。未来报告必须通过原始编码、贸易方向、伙伴唯一性、预览完整性、计量单位及全球额检查。同一产品的历史 HS8 沿用现有映射。已发布同年同方向序列须经过修订依据复核；因此本轮核对 2025 年数据可能不会增添一个新的年度图表点。
- CMS 已接上 Part B 季度开支和 ASP、Part D 年度费用的解析，并在既有图表和表格追加缺失期。数据已经收录时保留现有历史版本。Part B 年度大文件单独留痕，若受限则继续使用已验证数据。
- ClinicalTrials.gov 用站内已确认的 NCT 编号刷新个案，并按分子及申办方发现候选。候选不替代专题内人工核实的管线里程碑。FDA 分开记录首次与补充批准，沿用核实的参照药／类似药关系，缺少足够源证据的分类保持未确定。

## 审核

```sh
python scripts/review_data.py --list
python scripts/review_data.py TASK_ID
python scripts/review_data.py TASK_ID --approve-sha256 RECEIPT_SHA256
python scripts/research/legacy_ccc_audit.py
python scripts/build/replay_research.py
```

未批准的收执及源文件位于 .review-work，Git 忽略该目录。审核人核对收执中的官方文件、提取结果、比较基准、旧记录、修改差异与校验结果。通过后，人工运行可以提交工作树或在 GitHub 的 Manual data update 下输入任务 ID 和核准摘要进行同一检查及部署。相同版本成功重跑幂等，官方文件修订后须生成新收执。已核准版本的来源、修改依据、前后值和审核时间在 logs/reviewed 下。Linux 的审核环境使用 tesseract-ocr、tesseract-ocr-chi-sim 与 tesseract-ocr-chi-tra。Python 依赖见 requirements-updates.txt。

## 覆盖率

查看数据更新中心。来源监测按已配置真实更新入口统计，自动提取按已通过记录级检查和已批准的结构化抽取统计，审核按注册表中需要判断的集合统计。端到端自动化要求实际图表消费新增数据并通过云端校验，来源目录和公告发现不计入。需要批准后发布的更新体现在提取、审核和各行的最近成功更新时间。
